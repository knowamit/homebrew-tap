# homebrew-tap

Homebrew tap for [macoptimize](https://github.com/knowamit/macoptimize) and other macOS tools by [@knowamit](https://github.com/knowamit).

## Install

```bash
brew install knowamit/tap/macoptimize
```

Or tap first, then install:

```bash
brew tap knowamit/tap
brew install macoptimize
```

## Upgrade

```bash
brew upgrade macoptimize
```

## Uninstall

```bash
brew uninstall macoptimize
brew untap knowamit/tap
```

## Available formulae

| Formula | Description |
|---------|-------------|
| [macoptimize](https://github.com/knowamit/macoptimize) | macOS Apple Silicon performance optimizer, system monitor, and universal cache scanner |
